# Cloak v0.1.0 — Privacy-First Local P2P Communication Workspace

Privacy-first, self-hostable direct peer-to-peer communication workspace built with Rust, native Windows WebView2, and SQLite.

### Highlights
- **Strict Zero-Server P2P Networking:** Direct LAN & Tailscale/WAN encrypted transport (Ed25519/X25519, ChaCha20-Poly1305, Argon2id).
- **Stealth Mode & Offline PDF Cover:** Plausible deniability disguise with real embedded PDF.js reader. Switching to PDF cover locks the workspace; enter `#cloak` (or `cloak`) to return.
- **Ghost Mode:** Configurable local disappearing messages, privacy shield with PIN, and anti-resurrection guarantees.
- **Real-Time Voice, Video & Screen Sharing:** Direct peer-to-peer WebRTC media with Win32 hardware window capture.
- **Editorial Aesthetic:** Selvester-inspired stone/sage and deep forest palettes with serif typography and responsive layouts.
