- **Branch:** `recovery/p2p-desktop`
- **Version:** `0.1.0`
- **Assessment Basis:** Direct audit of source code, security controls, native Win32/WebView2 behavior, hardware media/GDI capture, silent installer/uninstaller runs, and post-final-edit automated tests. Historical claims from prior phases are superseded by verified Phase 11 measurements below.

## 3. Hardening Changes Implemented in Phase 11

1. **Sealed Binary Attachments at Rest (`crates/cloak-p2p/src/crypto.rs`, `storage.rs`):** Added `VaultSecretBox::seal_bytes` / `open_bytes` (`CLKBLOB1` + 24-byte `XNonce` + `XChaCha20-Poly1305`) bound to `vault.dpapi`; prevented orphan chunk writes without valid `attachment_meta`.
2. **Database & Sync Authorization Fixes (`storage.rs`, `transport.rs`):** Constrained `upsert_received_message`'s `ON CONFLICT(id) DO UPDATE` to matching `sender_device_id` and `room_id`; gated inbound `WireFrame::SyncRequest` on known local `room_id`.
3. **Production Gate on Stealth Test Clock (`main.rs`, `server.rs`, `stealth-mode.spec.ts`):** Disabled `/p2p/v1/stealth/test-clock-advance` by default (`403 FORBIDDEN` / `TEST_CLOCK_DISABLED`), enabled only via `--enable-test-clock` or `CLOAK_ENABLE_TEST_CLOCK=1`.
4. **PDF Search vs Auth Lockout Separation (`PdfReaderShell.tsx`, `stealth_controller.rs`):** Ensured ordinary in-document PDF searches do not increment persistent lockout counters (`failed_attempts`), while isolating high-rate misses into an in-memory burst cooldown.
5. **Win32 GDI Capture Fix & FPS Uncap (`capture.rs`, `P2pWorkspacePage.tsx`):** Fixed `SelectObject` ordering prior to `GetDIBits`, added primary desktop DC fallback, clarified GDI errors, and removed the redundant 30 fps UI cap.
6. **Window/Tray Icon Alignment (`native_shell.rs`):** Updated the embedded `32x32` RGBA native shell icon palette to Signal Teal / sky accent.

## 4. Measured Performance & Resource Footprint

- **Headless Mode (`cloak-desktop.exe --headless`, baseline pre-`capture.rs` patch):** Startup to HTTP-ready `1063.1 ms`, idle RAM `14.75 MiB`, 50 P2P messages `354.1 ms`, 2 MiB file transfer `892 ms`.
- **Full Native Desktop GUI (`cloak-desktop.exe`, Win32 + WebView2):**
  - Startup: `1187.3 ms` HTTP-ready, `1202 ms` HWND-ready, `3705.7 ms` settled GUI.
  - Memory (Rust + `8` WebView2 child processes): `49.5 MiB` Rust Working Set + `482.61 MiB` WebView2 Working Set = **`532.11 MiB` total Working Set** (**`270.98 MiB` total Private Memory**).
- **Screen Capture Throughput (`win:528920` Cloak `1618x1072`):** `42.41 ms` avg (`23.6 fps`) at `1280px` width; `44.38 ms` avg (`22.5 fps`) at `1920px` width.
